# Exercícios Java

Repositório criado para registrar minha evolução nos estudos de Java e Programação Orientada a Objetos.

## Projetos

### Cadastro de Clientes

Projeto desenvolvido para praticar:

- Classes e Objetos
- Programação Orientada a Objetos (POO)
- ArrayList
- Scanner
- Estruturas de repetição (`for` e `do-while`)
- Estruturas condicionais (`if`)
- Validação de dados

### Funcionalidades

- Cadastro de múltiplos clientes
- Validação da idade
- Listagem de clientes cadastrados

## Tecnologias

- Java
- IntelliJ IDEA
